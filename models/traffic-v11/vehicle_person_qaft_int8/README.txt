Vehicle/person OpenVINO INT8 model with variable batching

Files: model.xml and model.bin must stay together.
predict_openvino.py runs inference without PyTorch.
All nine original classes retained: bus, car, minivan, motorcycle, rickshaw, truck, bicycle, person, others.

Source: D:\TRAINING\vehicle_person_finetune\experiments\20261104T185716_594844Z_qaft\candidate_best.pt
Checkpoint SHA256: 8fa716bf26f92037522256a50a38fa6fb1de830277bf6f440c02146f8beae000
This model preserves the QAFT-trained quantizers. No new PTQ/calibration/retraining.
Compiled CPU graph has 96 INT8 convolutions. Detection outputs and other operations
remain floating point; this is an INT8/mixed-precision graph.

Input: float32 [N,3,640,640], RGB /255, letterboxed with padding 114.
N is dynamic. Batches 1,2,3,4,8,16 tested. Larger batches depend on memory.
Output: float32 [N,300,6], xyxy coordinates on 640x640 input, confidence, class ID.
YOLO26 end-to-end top-300 output; no extra NMS is required.
The supplied runner filters confidence and maps boxes to original image coordinates.

Run on .95 in PowerShell:
Set-Location -LiteralPath 'D:\TRAINING\vehicle_person_finetune\exports\vehicle_person_openvino_int8'
& 'C:\Program Files\Python311\python.exe' .\predict_openvino.py --source 'D:\TRAINING\unique_images' --batch 8 --output 'D:\TRAINING\vehicle_person_finetune\exports\predictions.json'

Change --batch to any positive integer. Final partial batches run at their actual size.
--source accepts an image, a directory, or a text file with one image path per line.
--conf defaults to 0.25. --threads defaults to 8.
